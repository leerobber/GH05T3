# Partner Adoption Risk - Data Leakage

Identifies the risk of data leakage and shadow IT arising from incomplete adoption of a centralized AI solution within a partnership or team environment.

## When to use
When assessing the security and compliance implications of a new AI or software solution where adoption is not universal.

## How to apply
1. **Identify Non-Adopters:** Determine the percentage of users who are unlikely to adopt the solution.
2. **Assess Alternative Behaviors:** Understand what these non-adopters will do to achieve the same goals (e.g., using unapproved tools, manual processes).
3. **Evaluate Data Leakage Pathways:** Map out how data could be exposed through these alternative behaviors (e.g., sharing documents via personal email, using public search engines).
4. **Quantify Impact:** Estimate the potential impact of a data breach resulting from these pathways (e.g., financial penalties, reputational damage).
5. **Mitigation Strategies:** Implement controls to minimize the risk, such as data loss prevention (DLP) policies, user training, and alternative solution provision.
