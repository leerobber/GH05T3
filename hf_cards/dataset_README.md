# SovereignEconomy v3

A rich behavioral economics dataset generated by a long-running multi-agent economy simulation.
**14,740+ ticks** of emergent economic behavior across **1,409 agents** spanning **15+ generations** —
births, deaths, inheritance, insurance, loans, guilds, governance, wealth taxes, UBI, and more.

## Dataset Contents

### Config: `sft` — Supervised Fine-Tuning (Alpaca format)
**Split:** `train` (~1,400 pairs)

Merged from all curated sources:

| Source | Pairs | Description |
|--------|-------|-------------|
| SPIN adversarial self-play | 471 | Sovereign strategy prompts with winning/losing reasoning chains |
| Bootstrap knowledge | 230 | Foundational economic and governance principles |
| Mentor training | 233 | Agent mentorship, task coaching, skill development |
| Web research | 314 | Real-world economics, finance, governance Q&A |
| Business/domain | 75 | Iron Mesa, business mesa, business docs |
| Agent personalities | 12 | GH05T3 specialists (CHRONICLE, CODEX, FORGE, NEXUS, ORACLE, SENTINEL) |
| Sovereign Nation domain | 23 | SovereignNation-specific knowledge |
| Avery mentor | 7 | Avery AI personality and behavioral guidance |

**Format:**
```json
{"instruction": "...", "response": "...", "domain": "..."}
```

---

### Config: `dpo` — Direct Preference Optimization
**Splits:** `spin_business_dpo`, `bootstrap_dpo`

Preference pairs with `prompt`, `chosen`, `rejected`, `domain` fields.
- **spin_business_dpo** — adversarial SPIN pairs: chosen = sovereign reasoning, rejected = weak/naive responses
- **bootstrap_dpo** — bootstrap preference pairs from foundational knowledge

**Format:**
```json
{"prompt": "...", "chosen": "...", "rejected": "...", "domain": "..."}
```

---

### Config: `agents` — Multi-Agent DPO
**Split:** `train` (35 pairs)

Agent-specific preference pairs for GH05T3 specialist agents (avery, forge, oracle, codex, sentinel, nexus).

## Economy Architecture

The simulation runs on a custom **FastAPI + PostgreSQL** stack with:

- **Tick engine** — 46 registered phases, 0.5s interval, batch size 5
- **Agent lifecycle** — birth, hibernation, retirement, death, inheritance
- **FEP-driven behavior** — Free Energy Principle active inference
- **Novelty engine** — MAP-Elites behavioral coverage tracking
- **Guild system** — 15 guilds, 1,190 guilded agents, 1.4M+ treasury
- **Finance** — loans, insurance, UBI, payroll contracts, government bonds
- **Governance** — constitutional proposals, council votes, wealth tax autopilot
- **Gini autopilot** — automatic redistribution when inequality exceeds threshold
- **A2A messaging** — agent-to-agent communication, coalition formation
- **Tool system** — T1/T2/T3 tool calls, tool registry, call history
- **ARSO orchestrator** — 7 specialist AI agents running parallel evolution cycles
